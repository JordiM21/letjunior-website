# characters/ — mascots and props

**Replaces:** the 🐙 and 🦕 peeking over the final CTA panel; anything else
playful we add later.
**How many:** 2 minimum, more is better.
**Send:** PNG-24 with transparency, **at least 600px on the long edge**.

Because the same characters recur, they must be drawn to one scale:

- **same canvas height for every character**, so relative sizes are right
  without me guessing in CSS;
- **transparent background** — no baked ground shadow, no frame, no white box;
- **10% empty padding** around the figure so nothing clips when it animates;
- one file per pose: `mascota-saluda.png`, `mascota-asoma.png`.

If they came out of Illustrator or Figma, send the source file too — it costs
you nothing and lets me re-crop without asking.
