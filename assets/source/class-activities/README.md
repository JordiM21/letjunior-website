# class-activities/ — what actually happens in a class

**Replaces:** nothing yet — this is new material, and the gap the site feels most.
**How many:** 6–12 to choose from.
**Send:** original camera/screen-capture JPEG, **at least 1600px wide**.

Right now the page *claims* the classes are fun and then shows emoji. These are
the pictures that make the Método section true: a teacher pulling a face, four
kids laughing at the same moment, a word game on screen, a puppet, the ukelele,
a whiteboard mid-drawing.

Shoot the class, not the product. Slightly messy and real beats staged and
clean. Screen recordings of the platform count — crop them to the game area.

**Consent:** any recognisable child needs written parental permission on file
before it ships. Send the ones you have consent for; hold the rest.
