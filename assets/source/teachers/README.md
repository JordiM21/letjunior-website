# teachers/ — the four portraits in "Conoce a tus profes"

**Replaces:** the 👩‍🦰 🧑‍🏫 👩‍🏫 🧔 emoji in `#profes`.
**How many:** one per teacher, minimum 4.
**Send:** original camera JPEG, **at least 1120px wide**, uncropped.

The biggest single quality risk on the whole site is four portraits that do not
match. Shoot or pick them to one brief:

- same background treatment, same crop distance, same eye-line height;
- framed loose enough that a 4:5 crop still has room;
- warm and human — they teach 7-year-olds, not tax law;
- straight off the camera. Do not pre-crop, do not filter, do not send the
  version already on Instagram.

Send the name and the real certification with each file — the page shows
"TEFL · 6 años con peques" under each face and those are currently invented.
